# Accessibility

**Target:** WCAG 2.2 AA (AAA for critical text where feasible).  
- Keyboard parity for primary flows  
- Focus ring: `0 0 0 2px canvas, 0 0 0 4px brand`  
- Status ≠ color alone  
- Chart data table toggle  
- Live regions: polite feeds; assertive Sev1  
- Skip link to main  
- RTL: logical properties (`margin-inline`, etc.)  
- i18n: no concatenated sentences in UI strings
